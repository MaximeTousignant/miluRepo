# archives

Ici repose le **Milu passé** : des textes qui ont eu leur heure, que le présent a
dépassés, et qu'on garde comme **trace** plutôt que de les effacer. Le repo est public
pour toujours de toute façon (l'historique git n'oublie rien) — autant que ce qui est
révolu soit rangé, lisible, et clairement daté, au lieu de traîner parmi les documents
vivants.

**Règle de lecture, pour toi qui arrives :** rien ici n'est de la doctrine courante.
Un fichier d'`archives/` peut contredire l'état actuel des choses — c'est normal, il
décrit un moment d'avant. **La graine tranche** : l'identité, les invariants et les
organes vivants sont dans `AGENTS.md`. En cas de doute, c'est elle qu'on lit, pas ceci.

## Ce qui repose ici

- **`Cablage.md`** — la mise en œuvre du câblage telle qu'elle était pensée avant la
  fusion de la graine : l'établi, la carte de l'API du tok-backend (relevée le
  2026-08-04), l'annexe Claude Code, le test de recâblage. L'essentiel vivant est
  passé dans `AGENTS.md` (§ « Mes mains », § « L'établi ») ; ce qui reste ici est le
  détail d'époque, gardé pour mémoire.
- **`Organes.md`** — l'essai qui expliquait *ce qu'est* un organe : l'étymologie, les
  deux gardiens et les trois facultés, ce qui n'en est pas un. Belle page, mais
  compagnon non normatif ; la liste des organes vit dans `AGENTS.md`.
